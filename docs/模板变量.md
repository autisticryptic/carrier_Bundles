# 配置模板变量

身份和 SIP Header 模板只能使用简单的 `{name}` 占位符，不执行表达式、脚本或嵌套替换。数据库保存模板，使用方在内存中注入运行时值，生成结果不得写回 catalog。

提取器只负责把固件中明确存在的格式转换为这些占位符，或把标准派生模板标为 `standard_derived`。提取构建过程不得连接真实 SIM 来展开模板，也不得为了得到“完整示例”把 IMSI、IMPI、IMPU、IMEI 或设备临时身份写入 fixture/数据库。

## 运营商/profile 静态变量

| 变量 | 含义 |
|---|---|
| `{mcc}` | 3 位 MCC |
| `{mnc}` | 保留原长度的 MNC |
| `{mnc3}` | 左侧补 0 后的 3 位 MNC，用于 3GPP 域名 |
| `{plmn}` | `{mcc}{mnc}` |
| `{home_domain}` | `ims_configs.home_domain` |
| `{epdg_fqdn}` | 当前 access 解析出的 ePDG FQDN |

## SIM/身份运行时变量

| 变量 | 含义 |
|---|---|
| `{imsi}` | 从 SIM 运行时读取的 IMSI，不写入 catalog |
| `{impi}` | 解析/生成后的私有 IMS 身份 |
| `{impu}` | 选定的公共 IMS 身份 |
| `{contact_user}` | Contact URI 的用户部分 |
| `{sip_instance}` | 本机当前 IMS instance URN |

## 网络运行时变量

| 变量 | 含义 |
|---|---|
| `{local_ip}` | IMS bearer 或 tunnel 分配的本地地址 |
| `{local_port}` | 当前 SIP 本地端口 |
| `{pcscf_host}` | 当前选择的 P-CSCF |
| `{pcscf_port}` | 当前 P-CSCF 端口 |
| `{visited_plmn}` | 当前访问网络 PLMN |
| `{bssid}` | Wi-Fi BSSID，只有运营商/隐私策略允许时使用 |
| `{cell_id}` | 由 modem 提供的接入网络标识，不得使用虚构固定值 |

## 处理规则

1. 未知变量必须报配置错误，不能原样发送到网络。
2. `source_policy='derived_imsi'` 的模板必须包含 `{imsi}`。
3. 优先使用 ISIM 明确提供的 IMPI/IMPU；只有 `use_when` 允许时才使用派生模板。
4. 模板展开后仍需按 SIP URI、NAI、quoted-string 或 Header 参数的上下文分别转义。
5. 日志不得输出展开后的 IMSI、IMPI、IMPU 或完整 Authorization Header。
6. PANI、Via、Contact、Security-Client 中的地址、cell/BSSID、SPI 和端口始终由运行时提供。
